Set up your Android phone

  1. Install the app. Easiest: plug the phone in with a USB cable (USB debugging on) and press the button. Or copy Bluey.apk to the phone and open it.
  2. Connect. Same Wi-Fi as this PC, open Bluey on the phone, it finds this PC by itself. No shared Wi-Fi? Keep the USB cable plugged in; that works too.
  3. Pair once. The phone and this PC show the same six digits. Click Allow here if they match.
No cable needed: point your phone's camera at this code (same Wi-Fi), tap the link, then Download Bluey and install it.
Let Bluey use my phone with no app permission (wireless debugging)
  1. Phone: Settings → About phone → tap MIUI version 7 times. Then Settings → Additional settings → Developer options → turn on USB debugging and Wireless debugging. (On Xiaomi/Redmi also turn on USB debugging (Security settings).)
  2. Tap Wireless debugging → Pair device with pairing code. Type the IP:port and 6-digit code here.
  3. Go back one screen, type the main IP address & Port here and press Connect.
